# skills

Skills pour agents de code (format Claude Code : un dossier par skill, un `SKILL.md` à frontmatter).
Chacun est agnostique — aucun nom, secret ni détail de projet — et se personnalise à l'installation.

| Skill | Rôle | Installer |
|---|---|---|
| [`simple`](simple/) | Rejouer une explication que l'utilisateur n'a pas comprise, en changeant de registre au lieu d'ajouter des détails. FR + EN. | dire à l'agent : « installe le skill `simple` en suivant `skills/simple/INSTALL.md` » |
